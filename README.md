# سیستەمی خشتەی هەفتانەی قوتابخانە — وەشانی دێسکتۆپ

بەرنامەیەکی ڕەسەنی ویندۆز کە **بەبێ XAMPP** کار دەکات. هەموو شتێک (سێرڤەری PHP، بنکەی زانیاری) لە ناو خودی بەرنامەکەدایە.

## جیاوازی لەگەڵ وەشانی XAMPP
- **پێویستی بە XAMPP نییە** — تەنها بەرنامەکە دابمەزرێنە و بیکەرەوە
- بنکەی زانیاری SQLite ـە (فایلێکی بچووک بە ناوی `timetable.db`)، نەک MySQL
- یەکەم جار کە دەیکەیتەوە، بنکەی زانیارییەکە خۆکارانە دروست دەبێت
- پێویستی بە مافی Administrator نییە. لە `C:\TimetableSystem` دادەمەزرێت
- ⚠ نابێت ڕێڕەوی بەرنامەکە بۆشایی (space)ی تێدابێت، بۆ نموونە `C:\Users\Ahmad Ali\...` — بۆ وەشانی پۆرتەبڵیش لە شوێنێکی وەک `C:\TimetableSystem` دایبنێ

## دامەزراندن
**`TimetableSystem-Setup.exe`** لەسەر هەموو ویندۆزەکان کار دەکات و خۆی وەشانی گونجاو هەڵدەبژێرێت:

| ویندۆز | وەشان |
|---|---|
| ویندۆز 10 / 11 ی 64-bit | **مۆدێرن**: پەنجەرەی خۆی (PHP Desktop + Chrome) |
| ویندۆز 7 SP1، 8، 8.1، یان هەر ویندۆزێکی 32-bit | **هەموو ویندۆزەکان**: PHP ی 32-bit، لە Edge یان Chrome دەکرێتەوە |

- پێویستی بە مافی Administrator نییە. بە بنەڕەت لە `C:\TimetableSystem` دادەمەزرێت
- ⚠ وەشانی مۆدێرن: نابێت ڕێڕەوەکە بۆشایی (space)ی تێدابێت
- ⚠ وەشانی هەموو ویندۆزەکان: Internet Explorer پشتگیری ناکرێت. لەسەر ویندۆز 7، Chrome 109 یان Edge 109 دابمەزرێنە

**پۆرتەبڵ (بێ دامەزراندن):**
- `TimetableSystem-Portable-Win10-64bit.zip` ← بیکەرەوە و `TimetableSystem.exe` بکەرەوە
- `TimetableSystem-Portable-AllWindows.zip` ← بیکەرەوە و `start.vbs` بکەرەوە (`stop.vbs` بۆ داخستنی سێرڤەرەکە)

## بەکارهێنان
١. **ڕێکخستن:** ناوی قوتابخانە، ژمارەی ڕۆژەکانی هەفتە، ژمارەی بەشە وانەکان و کاتەکانیان دیاری بکە
٢. **بابەتەکان** و **ژوورەکان** زیاد بکە (ژوور تەنها بۆ تاقیگە و هۆڵی هاوبەش پێویستە)
٣. **مامۆستایان** زیاد بکە، میلاک و ئەو بابەتانەی دەیڵێنەوە دیاری بکە. بە دوگمەی 🗓 کاتە بەتاڵەکانیان دیاری بکە
٤. **پۆلەکان** زیاد بکە و بۆ هەر پۆلێک «پرۆگرام» پڕ بکەرەوە: هەر بابەتێک هەفتانە چەند وانە، کام مامۆستا، وانەی دووانی، ژوور و گرووپ
   (دوگمەی «کۆپیکردنی پرۆگرام» بۆ پۆلە هاوشێوەکان کات دەگەڕێنێتەوە)
٥. لە تابی خشتە، **⚙ دروستکردنی ئۆتۆماتیکی** بکە، یان بە دەست وانە دابنێ
٦. بە ڕاکێشان (drag & drop) وانەکان بگوازەوە یان ئاڵوگۆڕیان بکە، و کرتە لە وانە بکە بۆ دەستکاریکردن
٧. **↶ گەڕانەوە** (Ctrl+Z) هەر گۆڕانکارییەکی خشتە دەگەڕێنێتەوە
٨. **🖨 چاپ / PDF** و **⬇ Excel** بۆ پۆل، مامۆستا و ژوور
٩. تابی **ڕاپۆرت و پشکنین** هەموو کێشەکان پیشان دەدات: تێکهەڵچوونی کاتی بەتاڵ، میلاکی تێپەڕێنراو، وانەی کەم/زیاد

### دروستکەری ئۆتۆماتیکی چۆن کار دەکات؟
**قۆناغی ١ — دروستکردن:** هەر وانەیەکی پرۆگرام دەبێتە «یەکە» (تاک، دووانی، یان هاوبەش). یەکە قورسەکان یەکەم دادەنرێن
و هەر یەکەیەک دەچێتە ئەو خانەیەی کەمترین «سزا»ی هەیە. ئەگەر جێی نەبووەوە، یەکەیەکی ڕێگر دەگوازرێتەوە.

**قۆناغی ٢ — باشترکردن:** بە ملیۆنان گواستنەوە و ئاڵوگۆڕی هەڕەمەکی (simulated annealing) خشتەکە باشتر دەکات.

**ڕێگرییە سەختەکان (هەرگیز ناشکێنرێن):** تێکهەڵچوونی پۆل/مامۆستا/ژوور، کاتی بەتاڵ، میلاکی هەفتانە،
زۆرترین وانەی ڕۆژانەی مامۆستا، زۆرترین وانەی بەدوای یەکدا، یەک بابەت لە ڕۆژێکدا.

**ڕێگرییە نەرمەکان (ئاستی گرنگییان لە ڕێکخستندا دیاری دەکرێت):**
- کەمکردنەوەی بۆشایی مامۆستا (زۆرترین بۆشایی ڕۆژانە بۆ هەر مامۆستایەک)
- پۆل بێ بۆشایی بێت و لە بەشە وانەی ١ دەست پێبکات
- کاتی باشتری بابەت: بابەتی قورس لە سەرەتای ڕۆژ، وەرزش لە کۆتایی
- پەیوەندی بابەتەکان: «لە یەک ڕۆژدا نەبن» یان «بەدوای یەکدا بن»
- کەمترین وانەی ڕۆژانەی مامۆستا

**وانەی هاوبەش:** یەک مامۆستا بۆ چەند پۆلێک پێکەوە (هەمان ناوی «وانەی هاوبەش» لە پرۆگرامی هەموویاندا).

**ڕاپۆرتی کوالێتی:** بۆشایی هەر مامۆستایەک، بۆشایی پۆلەکان، و بەراوردی پێش و دوای دروستکردن.

### تایبەتمەندییەکانی تر
- **هێنان لە aSc TimeTables** (File ← Export ← aSc XML) و **لە Excel** (CSV)
- **مامۆستای جێگرەوە:** بۆ مامۆستای ئامادەنەبوو، مامۆستا ئازادەکان پیشان دەدرێن (هەمان بابەت یەکەم) و چاپ دەکرێن
- **📱 مۆبایل:** فایلێکی HTML کە بە WhatsApp/Telegram دەنێردرێت و بەبێ ئینتەرنێت دەکرێتەوە

## پاراستنی داتا (Backup)
- ڕۆژانە پاڵپشتییەکی ئۆتۆماتیکی دەگیرێت (٣٠ دانەی کۆتایی دەمێننەوە)
- لە تابی **ڕێکخستن و پاڵپشتی** دەتوانیت پاڵپشتی بگریت، دایبگریت، یان داتا لە فایلێکەوە بگەڕێنیتەوە
- پێش هەر گەڕاندنەوەیەک، پاڵپشتییەک لە داتای ئێستا دەگیرێت

**شوێنی داتا:** فایلی `timetable.db` و فۆڵدەری `backups` لە تەنیشت `TimetableSystem.exe` ـن.
ئەگەر بەرنامەکە بۆ هەموو بەکارهێنەران لە `Program Files` دامەزرێنرابێت، داتاکە دەچێتە `%APPDATA%\TimetableSystem`.

## بڵاوکردنەوەی وەشانی نوێ
هەر push ـێک بۆ `main` فایلەکان لە بەشی **Actions** وەک artifact دروست دەکات.
بۆ بڵاوکردنەوە وەک **GitHub Release**، tag ـێک بنێرە:
```
git tag v2.0.0
git push origin v2.0.0
```

## چۆن ئەم فایلانە دروست بوون؟
ئەم فایلانە بە GitHub Actions دروست دەبن (لەسەر کۆمپیوتەری ویندۆز لە هەورەوە). فایلە دروستکراوەکان ناچنە ناو ڕیپۆوە — لە Actions یان Releases دایانبگرە.
