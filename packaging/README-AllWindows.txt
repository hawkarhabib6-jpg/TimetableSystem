School Timetable - All Windows edition (32-bit and 64-bit, Windows 7/8/10/11)

1. Extract this folder to a place such as C:\TimetableSystem
2. Double-click start.vbs
3. The app opens in Microsoft Edge or Google Chrome.
   Internet Explorer is NOT supported: on Windows 7 install Chrome 109 or Edge 109.
4. To close the background server: double-click stop.vbs (or restart the computer).

Your data is saved in timetable.db next to start.vbs.
